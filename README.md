# Cyboard Imprint — ZMK Studio Firmware

Firmware releases for **wireless Cyboard Imprint** keyboards, required for
full [studio.cyboard.digital](https://studio.cyboard.digital) support,
including trackball configuration.

## Install

Grab both files from the
[latest release](https://github.com/Cyboard-DigitalTailor/cyboard-imprint-zmk-studio-firmware/releases/latest)
and follow the
[firmware update guide](https://docs.cyboard.digital/studio-firmware-update):

| Half | File |
|---|---|
| Left (the half you plug into USB for Studio) | `imprint_left-studio.uf2` |
| Right | `imprint_right.uf2` |

Wired Cyboards use [Vial](https://get.vial.today/) instead — see the
[vial-qmk releases](https://github.com/Cyboard-DigitalTailor/vial-qmk/releases).
